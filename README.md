## 2.0 변경 요약

**기억 엔진·데이터**
- 화면에 보이는 상태/기억률/복습 일정을 모두 하나의 기억 엔진으로 계산 (v1은 두 엔진이 섞여 "99%인데 학습 중" 같은 모순이 생김)
- 복습 일정 엔진을 고정 배수 반감기 모델에서 **FSRS**(`ts-fsrs`)로 교체: 단어마다 난이도(D)·기억 안정도(S)를 따로 계산하고, 기억할 확률이 90%로 떨어질 때 복습 (최대 간격 1년). 답 버튼은 모르겠어요=Again, 애매해요=Hard, 알아요=Good. 기존 기록은 복습 이력을 다시 계산해 1회 변환
- 정해진 간격 단계(1·4·12일)를 없앰. 연구상 "점점 늘어나는 간격" 자체보다 간격을 두는 것과 단어별 기억 상태가 중요함
- 통계 보정값(유지율 50~99% 강제, 0일 때 82/54/42 대체)과 하드코딩 망각곡선 그림 제거 → 실제 기록만 표시
- 샘플 단어 자동 생성 제거. 기본 단어장·AI 단어장 생성 기능 제거 (직접 넣은 단어만 학습)
- v1 사용자: 샘플 단어에 붙어 있던 가짜 복습 기록만 1회 초기화 (단어와 실제 기록은 유지)
- 앱 시작 때마다 단어를 조용히 삭제하던 자동 정리 제거 (단어장 메뉴의 수동 "표기 자동 정리"로 변경)
- 저장 실패(용량 부족 등) 시 화면에 경고 표시, 영구 저장소 요청
- 빠르게 "알아요"를 누르면 5분 뒤 재출제되고 영원히 장기 기억으로 못 넘어가던 버그 수정

**학습 흐름**
- 홈: "오늘 할 일 N단어 [시작하기]" 한 버튼. 범위·방식은 접힌 옵션으로
- 타이머 제거, 복습할 단어 + 하루 새 단어(기본 10개)만 출제, 다 하면 "오늘 완료"
- 세션 안에서 다시 나오는 카드는 연습으로만 처리(일정 이중 반영 버그 수정), 마지막 카드 재출제 누락 수정
- 답 버튼 아래에 다음 복습 시점 표시 (예: 1일 / 2일 / 3일)
- "약한 단어 연습"은 복습 일정에 영향 없음

**단어 추가**
- 한 단어: 단어만 입력하고 Enter → 사전에서 뜻·발음·예문 채움 → 확인 후 저장
- 붙여넣기 / 파일(XLSX·CSV·TXT·DOCX·PDF·이미지), 저장 전 미리보기·수정
- DOCX를 실제로 압축 해제해서 읽도록 수정
- 사전 검색 실패 시 가짜 데이터를 저장하지 않고 안내만 표시

**서버**
- `/api/ai/*` 요청 횟수 제한(IP당 10분 300회)과 입력 길이 제한
- 사용하지 않던 엔드포인트 제거, `/api/ai/extract-vocab`(사진·PDF) 추가

**디자인**
- "조용한 단어 카드" 컨셉: 종이색 배경, 먹색 글씨, 강조색 1개, 그림자·그라데이션·이모지 제거
- 다크 모드(기기 설정 따름 / 직접 선택), 최소 글자 크기 12px 이상, 단어는 세리프체
- 존재하지 않던 기능(알림 토글, 문장 모드 설정) 제거

## AI 없이 단어 읽기·채우기 (Gemini 제거)

- **사진**: 기기 안에서 [Tesseract](https://github.com/naptha/tesseract.js) OCR로 글자를 읽음 (배우는 언어 + 한국어). 인식 엔진과 언어 자료는 앱 서버가 npm 패키지에서 직접 제공 (`/ocr/*`), 처음 한 번 받은 뒤 브라우저에 저장됨
- **PDF**: [PDF.js](https://mozilla.github.io/pdf.js/)로 글자를 읽고, 스캔된 쪽은 OCR로 읽음
- **문서·표·텍스트**: 기존처럼 기기에서 바로 읽음. 단어만 있는 목록(뜻 없음)도 단어를 찾아 두고, 저장할 때 사전에서 뜻을 채움
- **뜻·발음·예문**: 앱 서버의 `/api/dict/lookup`이 무료 공개 서비스에서 찾음
  - 한국어 뜻: [MyMemory](https://mymemory.translated.net/) 번역 API (키 없음, 하루 사용량 제한 있음)
  - 영어 발음·품사·예문: [Free Dictionary API](https://dictionaryapi.dev/)
  - 영어 외 언어는 뜻만 채움
