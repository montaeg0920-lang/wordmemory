# VocaCurve 2.0 — 망각곡선 단어장

잊어버리기 직전의 단어만 골라 하루 몇 분 복습하는 단어장입니다. (React + Vite, Express 서버에서 Gemini 호출)

View your app in AI Studio: https://ai.studio/apps/c712fba2-50d8-41e0-9050-779a932b13f9

## 실행

1. `npm install`
2. `.env.local`에 `GEMINI_API_KEY` 설정 (AI Studio에서는 Secrets 패널이 자동으로 넣어 줍니다)
3. `npm run dev`

## 2.0 변경 요약

**기억 엔진·데이터**
- 화면에 보이는 상태/기억률/복습 일정을 모두 하나의 반감기 엔진(`scienceScheduler`)으로 계산 (v1은 두 엔진이 섞여 "99%인데 학습 중" 같은 모순이 생김)
- 통계 보정값(유지율 50~99% 강제, 0일 때 82/54/42 대체)과 하드코딩 망각곡선 그림 제거 → 실제 기록만 표시
- 샘플 단어 자동 생성 제거. 기본 단어장(영어·일본어·히브리어·헬라어)은 원할 때 불러오기
- v1 사용자: 샘플 단어에 붙어 있던 가짜 복습 기록만 1회 초기화 (단어와 실제 기록은 유지)
- 앱 시작 때마다 단어를 조용히 삭제하던 자동 정리 제거 (단어장 메뉴의 수동 "표기 자동 정리"로 변경)
- 저장 실패(용량 부족 등) 시 화면에 경고 표시, 영구 저장소 요청
- 빠르게 "알아요"를 누르면 5분 뒤 재출제되고 영원히 장기 기억으로 못 넘어가던 버그 수정

**학습 흐름**
- 홈: "오늘 할 일 N단어 [시작하기]" 한 버튼. 범위·방식은 접힌 옵션으로
- 타이머 제거, 복습할 단어 + 하루 새 단어(기본 10개)만 출제, 다 하면 "오늘 완료"
- 세션 안에서 다시 나오는 카드는 연습으로만 처리(일정 이중 반영 버그 수정), 마지막 카드 재출제 누락 수정
- 답 버튼 아래에 다음 복습 시점 표시 (10분 / 1일 / 4일)
- "약한 단어 연습"은 복습 일정에 영향 없음

**단어 추가**
- 한 단어: 단어만 입력하고 Enter → AI가 뜻·발음·예문 채움 → 확인 후 저장
- 붙여넣기 / 사진(OCR, Gemini) / 파일(XLSX·CSV·TXT·DOCX·PDF), 저장 전 미리보기·수정
- DOCX를 실제로 압축 해제해서 읽도록 수정, PDF·사진은 Gemini가 읽음
- AI 실패 시 가짜 데이터를 저장하지 않고 안내만 표시

**서버**
- `/api/ai/*` 요청 횟수 제한(IP당 10분 300회)과 입력 길이 제한
- 사용하지 않던 엔드포인트 제거, `/api/ai/extract-vocab`(사진·PDF) 추가

**디자인**
- "조용한 단어 카드" 컨셉: 종이색 배경, 먹색 글씨, 강조색 1개, 그림자·그라데이션·이모지 제거
- 다크 모드(기기 설정 따름 / 직접 선택), 최소 글자 크기 12px 이상, 단어는 세리프체
- 존재하지 않던 기능(알림 토글, 문장 모드 설정) 제거
