# 내 말투로 다듬기

사용자가 준 글을 사용자 본인이 쓴 것처럼 자연스럽게 다시 쓴다. 내용과 사실은 바꾸지 않고 말투, 어휘, 문장 길이, 리듬만 맞춘다.

## 순서

1. `references/voice-profile.md` 를 읽는다.
   - 비어 있거나 "아직 작성 전" 상태면, 사용자에게 평소 직접 쓴 글 2~3개(메시지, 블로그, 메모 등)를 달라고 한 번만 요청한다.
   - 받은 글을 분석해 프로필 항목을 채우고, 사용자에게 요약을 보여준 뒤 파일에 저장해도 되는지 묻는다.
   - 사용자가 샘플 없이 바로 진행하길 원하면, 대화에서 보인 사용자의 말투를 기준으로 쓴다.
2. 프로필에 맞춰 글을 다시 쓴다.
   - 존댓말/반말, 문장 끝맺음(~요, ~다, ~음 등), 자주 쓰는 표현, 이모지·느낌표 사용 빈도, 문단 길이를 맞춘다.
   - 원문의 뜻, 숫자, 고유명사, 링크는 그대로 둔다.
   - 사용자가 쓰지 않는 딱딱한 표현(예: "~에 대해 말씀드리자면", "결론적으로", 과한 나열)은 사용자 식 표현으로 바꾼다.
3. 다듬은 글을 먼저 보여주고, 크게 바뀐 부분이 있으면 아래에 한두 줄로 알려준다.
4. 사용자가 "이건 내 말투 아니야" 같은 피드백을 주면 고쳐 쓰고, 그 내용을 프로필의 "피하기" 또는 "자주 쓰는 표현"에 반영할지 묻는다.

## 지키기

- 사용자 본인 글을 다듬는 용도다. 다른 실존 인물을 사칭하는 글은 쓰지 않는다.
- 원문에 없는 주장이나 사실을 새로 넣지 않는다.
